## 💎 Особенности и структура сайта

1. **Цветовая палитра:** Изысканная светлая гамма с изумрудными и бирюзовыми акцентами в тон шелковой рубашки с фото специалиста (`#0d5c56`, `#0f766e`, `#14b8a6`, `#f0fdf9`).
2. **Hero-экран:** Профессиональное фото высокого разрешения, академический статус МГУ, плашки доверия и быстрые CTA-кнопки.
3. **Спектр запросов:** 6 ключевых направлений (тревога и паника, апатия, бессонница, самокритика, родительское выгорание, эмоциональная регуляция).
4. **Профессиональные границы:** Честный блок с ограничениями компетенций (РПП, зависимости, РАС), подчеркивающий доказательность и заботу о безопасности клиента.
5. **Интерактивная галерея дипломов:** 8 официальных документов с зумом и подробным описанием в модальном окне.
6. **Блок экспресс-самодиагностики:** Прямые ссылки на клинические тесты (шкалы Бека BAI и BDI-II, HADS, выгорание MBI, опросник схема-терапии YSQ).
7. **Полезные материалы из Telegram:** Интерактивные инструкции («Бросить якорь», «Правила сна», «Доброе письмо») и прямые ссылки на посты в канале «С психикой вальсируем».
8. **Условия и запись:** Прозрачная стоимость (5 000 ₽ / сессия), выбор темы запроса и формирование готового сообщения в Telegram и WhatsApp.
9. **FAQ & Кризисный дисклеймер:** Четкие ответы на частые вопросы клиентов.

## 🚀 Технический стек

* **Frontend:** React 19, Vite 6, Tailwind CSS 4, Lucide React
* **Контроль версий:** Git
* **CI/CD:** GitHub Actions (`.github/workflows/deploy.yml`)
* **Хостинг:** GitHub Pages

## 🛠 Локальный запуск и разработка

```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run dev
# Либо двойной клик по файлу: Запустить_сайт.bat

# Сборка продакшен-бандла
npm run build
```
